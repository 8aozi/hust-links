- 本仓库仅整理通用网站入口，不收录个人成绩、选课记录、学分进度、私人联系方式或带身份信息的登录链接。

- 历年政策与加分细则请在学校或学院官网查询最新版本。
- 部分链接沿用原站的 HTTP 地址；请留意浏览器安全提示，不要绕过证书警告。
- 欢迎通过 Issue 或 Pull Request 补充公开资源、修复失效链接，提交前请阅读 [贡献说明](CONTRIBUTING.md)。
